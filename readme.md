# taskmenu

Консольное интерактивное меню для [`Taskfile.yml`](https://taskfile.dev/). Показывает список задач и позволяет запускать их по одной или несколько за раз, в любом порядке.

## Возможности

- Список задач берётся из `task --list-all --json`.
- Запуск сразу нескольких задач (`task a b c`) в порядке выбора.
- `--dry-run` — печатать команды без выполнения (`task --dry`).

## Установка

1. Разместить `taskmenu` в ту же папку, где лежит `task`, либо в любое место из `PATH`. Утилита вызывает `task` из `PATH`, так что он должен быть доступен.
2. Запускать из папки с `Taskfile.yml`.

### Требования

- [`task`](https://taskfile.dev/installation/) должен быть установлен и доступен в `PATH`.
- `Taskfile.yml` — в текущей рабочей директории.

## Использование

```
taskmenu               интерактивное меню
taskmenu --dry-run     печатать команды без выполнения
taskmenu -h|--help     справка
taskmenu -v|--version  версия
```

### Интерактивный режим

| Клавиша         | Действие                                                       |
|-----------------|----------------------------------------------------------------|
| `↑` / `↓`       | переместить курсор (по кругу, список прокручивается за ним)    |
| `Space`         | выбрать / снять задачу; номера выбранных пересчитываются       |
| `Enter`         | запустить отмеченные задачи (или задачу под курсором)          |
| `r` / `Ctrl+R`  | перезагрузить список задач                                     |
| `Esc`           | выход                                                          |
| `q` / `Ctrl+C`  | выход                                                          |

После нажатия `Enter` появляется строка `args (Enter for none):` — можно передать дополнительные аргументы, они попадут в `task <name> <args>`.

### Пример

```
$ taskmenu
  ▶  1 build   Build the project
     2 test    Run tests
       lint    Run linters
       deploy  Deploy to production
```

Стрелками перемещайте курсор, `Space` отмечайте задачи (появится номер запуска), `Enter` запустит их в порядке выбора.
